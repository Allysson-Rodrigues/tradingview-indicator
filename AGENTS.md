# TradingView Analytical Tools Governance

Project-local governance for the tradingview-indicator repository.

## 1. Technical Standards
- Language: Pine Script v6.
- Architecture: Structured technical analysis indicators (FVG, RSI, multi-timeframe projection).
- Tooling: TradingView Pine Editor and manual visual regression testing.

## 2. Quality & Validation
- Code style: Explicit typing on variables, modular helper functions, and descriptive parameter inputs.
- Releases: Keep version tags synchronized in README, code headers, and GitHub releases.
